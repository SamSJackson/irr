Reliability of a Network depends on the use-case as well as the network.

A general definition of a reliable network could be 
	A Network is *reliable* if it can be used for data analysis without finding false data - not necessarily invalid. 

For the purposes of our paper, we consider reliability as follows:
	A Social Network is *reliable* if it can be used to assist in disaster response confidently without providing misinformation about a given disaster.
